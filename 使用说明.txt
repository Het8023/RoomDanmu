局域网弹幕房间 - 免安装版使用说明
================================

【启动】
1. 把整个文件夹解压出来（不要只拖 exe）
2. 双击「启动弹幕.bat」即可运行
3. 如果 Windows 弹出「已保护你的电脑/SmartScreen」，点「更多信息」→「仍要运行」

【首次使用】
- 右下角托盘出现深蓝色圆形图标（看不到就点托盘区 ^ 展开）
- 右键托盘图标 →「修改昵称…」改成你的名字
- 右键托盘图标 →「修改房间号…」输入发起人给你的 6 位房间号（如 ADFB9K），改完会弹系统通知确认，托盘菜单同步更新

【发弹幕】
- 按全局热键（默认 Ctrl+Shift+Enter）唤出输入框
- 打字回车发送，弹幕会飘过本机和其他同房间成员的屏幕
- 多显示器使用时，弹幕只在 Windows 设置的主屏幕显示；更换主屏或插拔显示器后自动适配
- 昵称在弹幕文字下方居中；「设置 → 弹幕外观」可独立配置显示时长、移动速度和方向
- 显示时长支持 1–30 秒；例如设置 3 秒，弹幕按当前速度移动，到 3 秒直接消失，不会为了跑完整个屏幕而加速；提前移出屏幕也会结束显示
- 移动速度支持 30–600 px/s；方向支持从右向左、从左向右、从下向上、从上向下；设置对之后收到的新弹幕生效
- Esc 或点空白处关闭输入框

【连不上？】
- 双方必须连接同一个 Wi-Fi / 路由器（公司网络/访客网络可能隔离设备）
- 双击「放行防火墙.bat」（弹 UAC 点"是"），每台电脑都要运行
- 确认双方房间号完全一致（大写），且双方托盘都显示同一个房间号
- 自动发现失败时：托盘 → 设置 → 对方 IP，填写对方在共同局域网内的 IPv4 地址并保存；本机 IP 也在设置中显示
- 在线人数包含自己，两台电脑成功连接时双方均显示 2 人
- 移动程序目录后，需要再次运行「放行防火墙.bat」
- 参考「给朋友的加入说明.md」

【设置】
- 右键托盘 →「设置…」：在左侧选择「弹幕外观」「快捷键」「房间与连接」，修改后点击底部「保存设置」
- 设置窗口可调整大小；支持在「房间与连接」中修改昵称、房间号和对方 IP
- 「设置 → 应用 → 开机自启动」可开启或关闭登录 Windows 后自动运行，开关即时生效；默认不会自动开启
- 免安装版移动程序文件夹后，请重新开启开机自启动，以更新启动位置
- 右键托盘 →「退出」：关闭程序
